### 10/26/26
Thinking of a name for this project, I originally wanted to use ANA - Astronomical News Aggregate. However, a quick search on the Apple App store shows several apps with those initials and I didn't want things to get confusing. So my second thought was ANE - Astronomical News and Encyclopedia. This could work, but it doesn't have oomph. I'm toying with AENEID or something similar. It's classy, memorable, and fun. But I don't yet know what all the letters would stand for lol. So here's some brainstorming I guess.
AENEID - Astronomical Encyclopedia, News, _, _, and Dictionary? I could use NEws to reduce the wordiness a bit, but I still have no clue what the I would stand for. Maybeeee... Interstellar?

Astronomical
Encyclopedia,
NEws, and
Interstellar
Dictionary

Hmmm... I like it kinda, but I don't think Interstellar is quite the right word. We can work on that, but I like it for now.

### 10/27/26
I've given the name more thought. I think I'll go with this: **Astronomic Encyclopedia: News, Exploration, and Infinite Discovery**, **AENEID** for short. I think it's catchy and memorable.

To be thorough, I looked up *aeneid* on [uspto.gov](https://tmsearch.uspto.gov/search/search-results). Seems like the only active trademark named aeneid is in the bird feeder industry, so there shouldn't be any competition there. Still, I'm going to add a tasker to register the trademark. But I think there isn't a lot of urgency there.

Also had the thought to add inspirational space quotes if there are loading screens. At this point I really don't know how fast this thing is going to be able to move, so there may not be loading screens at all. Obviously this is a low priority, but would be a nice touch. I'm also going to rework the projects page here on github, since there isn't really any reason at this point to have a "backlog" category or anything. Not like anyone would see what I'm working on anyway. I intended it more as a way for me to track what I still need to do, so it can be changed a bit.
